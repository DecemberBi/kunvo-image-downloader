## 简介

Kunvo Image Downloader 是一款专为高效办公设计的图片批量下载工具。无论是设计师寻找素材、电商卖家提取商品图，还是个人用户备份画报，它都能助你一键完成。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| **深度提取** | 智能识别网页中的所有图片，包括背景图和懒加载图片 |
| **实时预览** | 在下载前实时预览图片，支持手动选中或一键剔除不需要的内容 |
| **智能过滤** | 内置强大的过滤系统，支持按宽度、高度或文件格式进行精准筛选 |
| **智能去重** | 采用感知哈希（Perceptual Hash）算法，自动识别并跳过相似或重复图片，节省空间 |
| **灵活保存** | 支持自定义文件夹命名与文件重命名规则，让你的下载库井井有条 |
